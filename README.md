# CodeAlpha Basic Network Sniffer

## Project Overview

This project is a basic network sniffer developed using Python and Scapy.

The sniffer captures network packets and displays useful information such as:

- Source IP address
- Destination IP address
- Protocol
- Port
- Payload

## Technologies Used

- Python
- Scapy
- Npcap
- Windows

## Features

- Captures network packets
- Identifies TCP, UDP and ICMP protocols
- Displays source and destination IP addresses
- Displays destination port
- Displays available packet payload
- Provides basic packet analysis

## Installation

Install Scapy using:

```bash
pip install scapy

```text
Npcap is required on Windows for packet capture.

## How to Run

Open Command Prompt in the project folder and run:

```bash
python network_sniffer.py

The program will start capturing packets and display their information.
